操作ヘルプ

基本の流れ: 左の素材一覧から「🎥 カメラ」を選んで追加(クリック、またはタイムラインへドラッグ)。 または、ドラッグで見回しながら WASD で良いアングルへ行って F。
動かしたい時は、再生ヘッドを進めて別のアングルへ行き K(これで動くショットになります)。 細かい位置・角度は、タイムラインのカメラをダブルクリックして数値で直せます。Space で再生して確認。

視点の操作

何も無い所をドラッグ見回す(左・右どちらのボタンでも)
WASD移動(ドラッグ中は Space/Shift でも上下)
Q / E下降 / 上昇
ドラッグ中にホイール移動速度を変える
ホイール前後に移動
中ボタンドラッグ平行移動

カメラ

素材一覧後ろから・周りを回る等のカメラを追加(⚙で秒数・距離など)
カメラの素材どれもスクリプト。置いた後も、ダブルクリックで設定を変えると作り直せる。カスタムで自分で書ける(.js)
F今の構図で、再生ヘッドの位置にカメラを置く
K今の構図を、再生ヘッドの時刻のキーとして記録
L選んでいるブロック・人形をくっつける(① 自分の点 → ② 相手の点をクリック)
V選択中のカメラの目線に入る/戻る
カメラをダブルクリック位置・角度・画角・表示位置・動きの速さを直す(キーは自動で作られる)
箱 / ◆をクリックそのカメラを選ぶ / そのポイントの時刻へ
矢印 / リングをドラッグ再生ヘッドの時刻の位置 / 向きを直す(ポイントが無ければ自動で作る)
Shift+矢印 / リングカメラ全体(全ポイント)をまとめて動かす / 回す

タイムライン

Space再生 / 一時停止
← →1コマ移動(Shiftで1秒)
Home End先頭 / 最後へ
ルーラーをドラッグ再生ヘッドを動かす(Altで吸着しない)
Ctrl/Cmd+ホイール拡大・縮小(トラックパッドはピンチ)
ブロックを上下にドラッグカメラの重なり順(上ほど手前)
◆ をドラッグそのポイントの時刻を変える
カーブの○をドラッグポイントの間の速さ(ゆっくり始まる等)。Shiftで対称

編集

Ctrl/Cmd+Z取り消し
Ctrl/Cmd+Shift+Zやり直し
B選択中のブロックを再生ヘッドで分割
Ctrl/Cmd+D複製
Delete削除(◆を選んでいればそのポイントだけ)
ダブルクリック編集パネルを開く
ポーズタイムラインの「🕺 ポーズ」タブ。3Dでプレイヤー・人形を1回クリックすると、関節にリング(回す)と矢印(動かす)が出る。手足の先の○をドラッグで腕・脚が自動で曲がる(IK)。Shift+クリックで関節をまとめて選ぶ。K で選んだ関節のキー。ブロックをダブルクリックで関節の行が全部開く
パーティクル左の「💥 パーティクル」から。写真を読み込んで割れる・広がる動きにできる。3Dの矢印で位置、リングで向き
Escカメラ視点・パネルを閉じる / 選択を外す
